# curly-umbrella

A simple personal website: plain HTML and CSS, no build step.

## Edit it

- `index.html` holds the content. Replace "Your Name", the tagline, the About text, the projects and the email address.
- `styles.css` holds the look. Change `--accent` at the top to pick a different color.

To preview it, open `index.html` in a browser.

## Publish it free with GitHub Pages

1. On GitHub, open the repo's **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to "Deploy from a branch".
3. Choose branch `main` and folder `/ (root)`, then **Save**.

After a minute the site is live at `https://beyondaosc2020-hue.github.io/curly-umbrella/`.
